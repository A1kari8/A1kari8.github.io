## LeNet-5

特点是使用**平均池化**

网络结构：

|层级|名称|卷积核/操作|输出尺寸|
|---|---|---|---|
|输入层|Input|32x32灰度图像|1@32x32|
|C1|卷积层1|6个5x5卷积核，步长1|6@28x28|
|S2|平均池化层1|2x2平均池化，步长2|6@14x14|
|C3|卷积层2|16个5x5卷积核，步长1|16@10x10|
|S4|平均池化层2|2x2平均池化，步长2|16@5x5|
|C5|卷积层3|120个5x5卷积核，步长1|120@1x1|
|F6|全连接层|84个神经元|84|
|输出层|Output|10个神经元，softmax|10|

激活函数使用Tanh或Sigmoid

局限性：

- 梯度消失问题，网络变深会导致训练困难

## AlexNet

特点是使用**ReLU激活函数**、**最大池化**和**Dropout**

网络结构：

|层级|名称|卷积核/操作|输出尺寸|
|---|---|---|---|
|输入层|Input|224x224 RGB图像|3@224x224|
|Conv1|卷积层1|96个11x11卷积核，步长4|96@55x55|
|Pool1|最大池化层1|3x3最大池化，步长2|96@27x27|
|Conv2|卷积层2|256个5x5卷积核，步长1，pad=2|256@27x27|
|Pool2|最大池化层2|3x3最大池化，步长2|256@13x13|
|Conv3|卷积层3|384个3x3卷积核，步长1, pad=1|384@13x13|
|Conv4|卷积层4|384个3x3卷积核，步长1, pad=1|384@13x13|
|Conv5|卷积层5|256个3x3卷积核，步长1, pad=1|256@13x13|
|Pool5|最大池化层5|3x3最大池化，步长2|256@6x6|
|Dropout|Dropout|丢弃50%的神经元|256@6x6|
|FC6|全连接层1|4096个神经元|4096|
|Dropout|Dropout|丢弃50%的神经元|4096|
|FC7|全连接层2|4096个神经元|4096|
|FC8|全连接层3|1000个神经元，softmax|1000|

## ResNet

特点是**跳跃连接**，不再让每层直接输出结果，而是输出跟结果的差异，解决了深层网络的梯度消失问题

### 残差块

- 恒等块：输入输出尺寸通道相同
- 投影块：输入输出尺寸通道不同，使用1x1卷积核进行升维或降维

|层级|名称|
|---|---|
|输入层|Input|
|Conv1|卷积层1|
|BN|批归一化|
|ReLU1|激活函数|
|Conv2|卷积层2|
|BN|批归一化|
|ReLU2|激活函数|
|输出层|Output|

#### BasicBlock(ResNet-18/ResNet-34)

为恒等块时，卷积过程中尺寸不会变化

#### Bottleneck(ResNet-50/ResNet-101/ResNet-152)

为恒等块时，卷积过程中会先降维，后升维

### ResNet-50

|层级|名称|卷积核/操作|输出尺寸|
|---|---|---|---|
|输入层|Input|224x224 RGB图像|3@224x224|
|Conv1|卷积层1|64个7x7卷积核，步长2, pad=3|64@112x112|
|Pool1|最大池化层1|3x3最大池化，步长2|64@56x56|
|Conv2_x|残差块1|3个瓶颈块|256@56x56|
|Conv3_x|残差块2|4个瓶颈块，首个块降采样|512@28x28|
|Conv4_x|残差块3|6个瓶颈块，首个块降采样|1024@14x14|
|Conv5_x|残差块4|3个瓶颈块，首个块降采样|2048@7x7|
|Pool2|全局平均池化|7x7平均池化，步长1|2048@1x1|
|FC|全连接层|1000个神经元，softmax|1000|

避免了AlexNet中FC参数过多的问题

## VGGNet

特点是整个网络全用3x3卷积核，全使用2x2最大池化

|层级|名称|卷积核/操作|输出尺寸|
|---|---|---|---|
|输入层|Input|224x224 RGB图像|3@224x224|
|Block1|卷积块1|Conv3-64 x 2 + MaxPool|64@112x112|
|Block2|卷积块2|Conv3-128 x 2 + MaxPool|128@56x56|
|Block3|卷积块3|Conv3-256 x 3 + MaxPool|256@28x28|
|Block4|卷积块4|Conv3-512 x 3 + MaxPool|512@14x14|
|Block5|卷积块5|Conv3-512 x 3 + MaxPool|512@7x7|
|FC|全连接层|4096 + 4096 + 1000|1000|
|输出层|Output|Softmax|1000|

缺点：

- 参数量巨大

## GoogLeNet

特点是使用**Inception模块**，在同一层中使用不同大小的卷积核进行卷积操作

### Inception模块(降维版)

输出同时进入4条并行支路，最后拼接

|支路|操作|作用|
|---|---|---|
|1|1x1卷积|降维|
|2|1x1卷积 + 3x3卷积|降维 + 提取局部中等感受野特征|
|3|1x1卷积 + 5x5卷积|降维 + 提取大感受野特征|
|4|3x3最大池化 + 1x1卷积|池化提取强特征 + 调整通道数|

通过设置padding使4条支路的输出尺寸相同

网络结构：

|层级|名称|卷积核/操作|输出尺寸|
|---|---|---|---|
|Stem|入口模块|Conv7 + MaxPool + Conv1 + Conv3 + MaxPool|192@28x28|
|Inception3a/3b|两个Inception模块||256/480@28x28|
|MaxPool|最大池化层||480@14x14|
|Inception4a/4b/4c/4d/4e|五个Inception模块||832@14x14|
|MaxPool|最大池化层||832@7x7|
|Inception5a/5b|两个Inception模块||1024@7x7|
|Pool|全局平均池化|把图压成一个点替代全连接|1024@1x1|
|Dropout|Dropout|丢弃40%的神经元|1024@1x1|
|FC|全连接层|1000个神经元，softmax|1000|
